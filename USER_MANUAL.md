## 1. GETTING STARTED

### 1.1 System Requirements

**Minimum Requirements:**
- Modern web browser (Chrome 90+, Edge 90+, Firefox 88+)
- Internet connection (2 Mbps minimum)
- Microphone for voice interviews
- Webcam (optional)

**Recommended:**
- Chrome or Edge browser (for best voice recognition)
- 5 Mbps internet connection
- Headset with microphone
- HD webcam

### 1.2 Account Registration

**Step 1: Access the Platform**
- Navigate to: http://localhost:5000 (or your deployment URL)
- Click "Get Started" or "Sign Up"

**Step 2: Choose Account Type**
- Select "Student" for interview practice
- Select "HR Professional" for recruitment management

**Step 3: Fill Registration Form**

**For Students:**
- Full Name
- Email Address
- Password (min 8 characters)
- Phone Number
- College/University
- Degree Program
- Year of Study
- Skills (comma-separated)

**For HR Professionals:**
- Full Name
- Email Address
- Password
- Company Name
- Designation
- Department
- Phone Number

**Step 4: Verify Email**
- Check your email for verification link
- Click the link to activate account

## 2. STUDENT GUIDE

### 2.1 Dashboard Overview

**Main Sections:**
- **Profile Summary:** Your details and statistics
- **Quick Actions:** Start practice, view feedback
- **Recent Interviews:** History of past interviews
- **Performance Metrics:** Scores and progress

### 2.2 Starting a Practice Interview

**Step 1: Navigate to Practice Interview**
- Click "Practice Interview" from dashboard
- Or use the "Start Practice" button

**Step 2: Configure Interview Settings**
- **Job Role:** Select from dropdown (e.g., Software Developer)
- **Difficulty:** Easy, Medium, or Hard
- **Experience Level:** Fresher, 1-2 years, 2-3 years, 3+ years
- **Number of Questions:** 5-10 questions

**Step 3: Upload Resume (Optional)**
- Click "Upload Resume"
- Select PDF file (max 5MB)
- AI will extract skills for personalized questions

**Step 4: Start Interview**
- Click "Start Interview"
- Allow microphone access when prompted
- Wait for AI to load first question

### 2.3 During the Interview

**Voice Input:**
1. Wait for AI question
2. Speak clearly into microphone
3. Answer will be captured automatically
4. Wait for next question

**Text Input:**
1. Type answer in input field
2. Click "Send" or press Enter
3. Wait for AI response

**Tips for Best Results:**
- Speak clearly and at moderate pace
- Provide detailed answers (3-5 sentences minimum)
- Use STAR method for behavioral questions
- Give specific examples from experience

### 2.4 Viewing Feedback

**After Interview:**
- Feedback page loads automatically
- Review overall score and breakdown
- Read strengths and weaknesses
- Check improvement recommendations
- Download PDF report

**Feedback Sections:**
- **Overall Score:** 0-100 scale
- **Technical Score:** Technical knowledge assessment
- **Communication Score:** Clarity and structure
- **Problem-Solving Score:** Analytical thinking
- **Detailed Analysis:** Comprehensive breakdown
- **Recommendations:** Actionable next steps

### 2.5 Profile Management

**Update Profile:**
- Click profile icon → "Edit Profile"
- Update information
- Click "Save Changes"

**Upload Resume:**
- Go to Profile → "Upload Resume"
- Select PDF file
- AI extracts skills automatically

**View History:**
- Dashboard → "Interview History"
- Click any interview to view details
- Download past feedback reports

## 4. TROUBLESHOOTING

### 4.1 Common Issues

**Issue: Microphone Not Working**

**Solution:**
1. Check browser permissions
2. Go to browser settings → Privacy → Microphone
3. Allow access for the website
4. Refresh the page
5. Try different browser (Chrome recommended)

**Issue: Voice Not Being Captured**

**Solution:**
1. Speak clearly and loudly
2. Check microphone is not muted
3. Test microphone in system settings
4. Use headset instead of built-in mic
5. Reduce background noise

**Issue: Interview Not Starting**

**Solution:**
1. Check internet connection
2. Clear browser cache
3. Disable browser extensions
4. Try incognito/private mode
5. Contact support if issue persists

**Issue: Feedback Not Loading**

**Solution:**
1. Wait 30 seconds (AI processing time)
2. Refresh the page
3. Check browser console for errors
4. Try different browser
5. Contact support with session ID

**Issue: Email Not Received**

**Solution:**
1. Check spam/junk folder
2. Verify email address is correct
3. Wait 5 minutes for delivery
4. Request resend from dashboard
5. Contact support if not received

### 4.2 Browser Compatibility

**Fully Supported:**
- Google Chrome 90+
- Microsoft Edge 90+
- Firefox 88+

**Partially Supported:**
- Safari 14+ (voice features limited)
- Opera 76+

**Not Supported:**
- Internet Explorer
- Browsers older than 2 years

### 4.3 Performance Issues

**Slow Loading:**
- Check internet speed (min 2 Mbps)
- Close unnecessary tabs
- Clear browser cache
- Disable heavy extensions
- Try different time (off-peak hours)

**Audio Issues:**
- Use wired headset
- Close other audio applications
- Check system audio settings
- Update audio drivers
- Restart browser

## 5. FREQUENTLY ASKED QUESTIONS

### 5.1 General Questions

**Q: Is TalentSync free to use?**
A: Yes, the platform is completely free for students. HR professionals may have premium features.

**Q: How long does an interview take?**
A: Average interview duration is 10-15 minutes for 5 questions.

**Q: Can I pause the interview?**
A: No, interviews must be completed in one session for accurate evaluation.

**Q: How is my data protected?**
A: All data is encrypted and stored securely. We follow GDPR compliance.

**Q: Can I retake an interview?**
A: Yes, students can practice unlimited times. HR interviews are one-time only.

### 5.2 Student Questions

**Q: How accurate is the AI feedback?**
A: Our AI has 95%+ accuracy based on extensive testing and validation.

**Q: What if I make a mistake during the interview?**
A: Continue with your answer. AI evaluates overall performance, not individual mistakes.

**Q: Can I see my previous interview answers?**
A: Yes, go to Dashboard → Interview History → View Details.

**Q: How do I improve my score?**
A: Follow the recommendations in feedback, practice regularly, and provide detailed answers.

**Q: Does the AI understand different accents?**
A: Yes, the AI is trained on diverse accents and speech patterns.

### 5.3 HR Questions

**Q: How many candidates can I interview?**
A: Unlimited candidates can be interviewed simultaneously.

**Q: Can I customize interview questions?**
A: Yes, you can add custom questions when creating a job drive.

**Q: How do I export candidate data?**
A: Go to Analytics → Export → Select format and date range.

**Q: Can multiple HR users access the same account?**
A: Each HR professional needs their own account for security.

**Q: How long is candidate data stored?**
A: Data is stored for 2 years, then archived as per policy.

### 5.4 Technical Questions

**Q: What browsers are supported?**
A: Chrome, Edge, and Firefox (latest versions). Chrome recommended for voice features.

**Q: Do I need to install any software?**
A: No, TalentSync is completely web-based. No installation required.

**Q: What internet speed is required?**
A: Minimum 2 Mbps, recommended 5 Mbps for smooth experience.

**Q: Can I use TalentSync on mobile?**
A: The website is mobile-responsive, but desktop is recommended for interviews.

**Q: Is my interview recorded?**
A: Only text transcripts are stored. Audio/video is not recorded.
