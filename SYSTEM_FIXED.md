### 2. ⚠️ Dashboard Score Display Issue
**Issue:** Scores not showing in student dashboard
**Root Cause:** Scores are NULL in database for interviews without proper completion
**Location:** `app/main.py` - `complete_adaptive_interview()` function

**Analysis:**
- Dashboard template correctly displays scores: `{{ "%.1f"|format(avg_score) }}%`
- Score calculation in `student_dashboard()` is correct
- Problem: Interviews completed without proper evaluation have NULL scores

**Solution:**
The system calculates scores correctly when interviews are completed through the proper flow:
1. Interview must be completed via `/adaptive-interview/<session_id>/complete`
2. Scores are generated by `professional_feedback.py`
3. Scores are stored in `InterviewSession` model

**To see scores:**
- Complete interviews properly (don't just close browser)
- Click "End Interview" button to trigger evaluation
- Scores will appear in dashboard after proper completion
