## 🎯 MAIN SYSTEM DIAGRAM PROMPT

```
I need you to create a comprehensive system architecture diagram for my AI Interview System project. This is for my research paper and presentation.

PROJECT OVERVIEW:
An AI-powered interview platform that helps students practice interviews and HR professionals conduct efficient recruitment.

SYSTEM COMPONENTS:

1. USER LAYER:
   - Two user types: Students and HR Professionals
   - Access via web browser

2. WEB INTERFACE:
   - Responsive web application
   - Built with HTML5, CSS3, Bootstrap

3. AUTHENTICATION:
   - User registration and login
   - Role-based access control (Student/HR)
   - Session management

4. STUDENT WORKFLOW:
   - Create profile and upload resume
   - Start practice interview
   - AI generates personalized questions based on job role and profile
   - Answer questions (text/voice)
   - AI evaluates each answer in real-time
   - Receive instant feedback and scoring
   - View performance history and analytics

5. HR WORKFLOW:
   - Create company profile
   - Post job drives with requirements
   - Receive student applications
   - Review candidate profiles
   - Schedule interviews
   - AI-assisted candidate evaluation
   - Make hiring decisions
   - Access analytics dashboard

6. AI ENGINE (Core Innovation):
   - Uses LLM
   - Multiple AI models: Grok-4-Fast, DeepSeek, GPT-OSS
   - Generates interview questions adaptively
   - Evaluates student responses
   - Provides detailed feedback
   - Scores performance
   - Generates comprehensive reports

7. DATABASE:
   - Stores user profiles (students and HR)
   - Interview records and responses
   - Job postings and applications
   - Performance analytics
   - SQLite for development, PostgreSQL for production

8. FILE STORAGE:
   - Resume uploads
   - Profile photos
   - Generated reports

9. EXTERNAL SERVICES:
   - Email notifications (SMTP)
   - AI API (OpenRouter)

DIAGRAM REQUIREMENTS:

1. FORMAT: Create as Mermaid flowchart code that I can use

2. LAYOUT: Top-to-bottom flow showing:
   - User entry point
   - Authentication gate
   - Split into Student and HR paths
   - AI engine as central processing unit
   - Database storage
   - Results output

3. COLOR SCHEME (Professional):
   - User/Start nodes: Green (#4CAF50)
   - AI Processing nodes: Purple (#9C27B0)
   - Database nodes: Blue (#2196F3)
   - Results/Output nodes: Orange (#FF9800)
   - Decision nodes: Yellow
   - End nodes: Red (#F44336)

4. STYLE:
   - Clean and professional
   - Clear labels
   - Logical flow with arrows
   - Subgraphs for grouping related components
   - Suitable for academic paper and presentation

5. LEVEL OF DETAIL:
   - Not too complex (should fit on one slide)
   - Not too simple (should show key innovations)
   - Focus on the AI integration as the main feature
   - Show data flow clearly

DELIVERABLE:
Please provide:
1. Complete Mermaid diagram code
2. Brief explanation of the diagram structure
3. Suggestions for figure caption for research paper

This diagram will be the main figure in my research paper's system design section and a key slide in my presentation. Make it publication-ready for IEEE/Springer format papers.
```
